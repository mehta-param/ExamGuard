# Plan 02-02: Main Application Window, Timetable View & Dynamic Subject Filtering

## Goal
Implement the main JavaFX application window assembling the algorithm controls, the circular conflict graph canvas, the step-by-step playback bar, the conflict-free timetable view, and the interactive subject subset selection filter that dynamically rebuilds the graph.

## Requirements Covered
- **REQ-ANIM-05**: Subject subset selection: interactive checkbox selection allowing users to select/deselect subjects; dynamically rebuilds the active `ConflictGraph` and regenerates a valid timetable using only the selected subjects.
- **REQ-TIME-01**: Display conflict-free timetable view grouped by Timeslot with scheduled subjects.
- **REQ-TIME-02**: Automated conflict validator confirming zero student clashes across all slots with a visual status badge.

## Architecture & Constraints
- Pure Java layout in `com.examguard.ui.MainView` (`BorderPane`, `HBox`, `VBox`): Zero FXML reflection complexity.
- Reuses Phase 1 `ConflictGraphBuilder`, `WelshPowellAlgorithm`, `BacktrackingAlgorithm`, and `Schedule`.
- Deselecting any subject filters the in-memory list, calls `ConflictGraphBuilder.build(selectedSubjects, enrollments, students)`, updates the Canvas, and triggers schedule regeneration.

### Task 3: Main View Assembly & Dynamic Subset Filtering (`MainView.java`)
- **Files**:
  - `src/main/java/com/examguard/ui/MainView.java`
- **Actions**:
  - Extends `BorderPane`:
    - **Top Toolbar**:
      - Algorithm ComboBox: ["Welsh-Powell Greedy", "Recursive Backtracking"].
      - "Run & Animate" button: Executes algorithm, loads trace into `GraphAnimator`, starts playback.
      - "Instant Solve" button: Immediately displays final coloring and timetable without waiting for animation.
    - **Left Sidebar (Subject Subset Filter)**:
      - Title: "Active Subjects (Filter)"
      - CheckBox for each of the 6 subjects (initially all checked).
      - Helper buttons: "Select All", "Deselect All".
      - When any CheckBox toggles:
        1. Collect checked subjects.
        2. Rebuild active graph: `activeGraph = ConflictGraphBuilder.build(selected, enrollments, students)`.
        3. Redraw `GraphCanvas` with new vertex count.
        4. Recompute coloring and update timetable.
    - **Center**:
      - StackPane containing `GraphCanvas` (600x520).
      - Bottom bar: `Play`, `Pause`, `Step-Forward`, `Reset` buttons + Speed slider + Live Explanation Banner `Label`.
    - **Right Sidebar**:
      - `TimetablePanel` (300px width).
