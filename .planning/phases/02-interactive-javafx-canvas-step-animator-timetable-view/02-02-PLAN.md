# Plan 02-02: Main Application Window, Timetable View & Dynamic Subject Filtering

## Goal
Implement the main JavaFX application window assembling the algorithm controls, the circular conflict graph canvas, the step-by-step playback bar, the conflict-free timetable view, and the interactive subject subset selection filter that dynamically rebuilds the graph.

## Requirements Covered
- **REQ-ANIM-05**: Subject subset selection: interactive checkbox selection allowing users to select/deselect subjects; dynamically rebuilds the active `ConflictGraph` and regenerates a valid timetable using only the selected subjects.
- **REQ-TIME-01**: Display conflict-free timetable view grouped by Timeslot with scheduled subjects.
- **REQ-TIME-02**: Automated conflict validator confirming zero student clashes across all slots with a visual status badge.

## Safeguards & Architectural Invariants (User Explicit Mandates)
1. **Strict Active Graph Rebuild**: When subjects are selected or deselected, rebuild the active `ConflictGraph` from strictly the selected subjects and their enrollment data (`ConflictGraphBuilder.build(selectedSubjects, enrollments, students)`). Never retain conflicts or edges involving excluded subjects.
2. **State Invalidation on Selection Change**: If the selected graph changes, immediately stop any running animator timeline, reset animation step state, and invalidate any previous timetable and coloring state until a new solution is generated. The displayed timetable must always strictly match the current selection and chosen algorithm.
3. **Simplicity & Zero Added Complexity**: Keep the JavaFX UI simple, clean, and readable. Reuse existing pure Java algorithms and `ExecutionTrace`. Do not add dependencies, external frameworks, or extra architectural layers beyond the approved Phase 2 scope.

### Task 2: Timetable Card & Verification Panel Component
- **Files**:
  - `src/main/java/com/examguard/ui/TimetablePanel.java`
- **Actions**:
  - Extends `VBox`:
    - Title: "Exam Timetable Schedule"
    - Subtitle: Total timeslots used count
    - Status Badge: Green pill badge "Zero Conflicts Verified ✓" when `schedule.isValid(graph)` is true. If timetable is invalidated or not yet generated, displays a neutral "Awaiting Solution..." badge.
    - Card List: For each Timeslot (Slot 1, Slot 2, ...), renders a styled card showing the slot number, scheduled subject badges, and student count.
  - Methods:
    - `updateSchedule(Schedule schedule, ConflictGraph graph)`
    - `clearSchedule()` / `invalidate(String reason)`: Resets timetable view to empty state with invalidation notice.

### Task 3: Main View Assembly & Dynamic Subset Filtering (`MainView.java`)
- **Files**:
  - `src/main/java/com/examguard/ui/MainView.java`
- **Actions**:
  - Extends `BorderPane`:
    - **Top Toolbar**:
      - Algorithm ComboBox: ["Welsh-Powell Greedy", "Recursive Backtracking"].
      - "Run & Animate" button: Executes selected algorithm on active graph, loads trace into `GraphAnimator`, starts playback.
      - "Instant Solve" button: Immediately displays final coloring and timetable without waiting for animation.
    - **Left Sidebar (Subject Subset Filter)**:
      - Title: "Active Subjects (Filter)"
      - CheckBox for each of the 6 subjects (initially all checked).
      - Helper buttons: "Select All", "Deselect All".
      - When any CheckBox toggles:
        1. Collect checked subjects.
        2. Invalidate previous timetable and animation state: stop animator, clear colors on canvas, call `timetablePanel.invalidate(...)`.
        3. Rebuild active graph from scratch: `activeGraph = ConflictGraphBuilder.build(selected, enrollments, students)`.
        4. Redraw `GraphCanvas` geometry and empty uncolored nodes with new vertex count.
    - **Center**:
      - StackPane containing `GraphCanvas` (600x520).
      - Bottom bar: `Play`, `Pause`, `Step-Forward`, `Reset` buttons + Speed slider + Live Explanation Banner `Label`.
    - **Right Sidebar**:
      - `TimetablePanel` (300px width).
