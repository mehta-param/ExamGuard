# Plan 02-01: Circular Graph Canvas & Step Animator

## Goal
Build the custom JavaFX `GraphCanvas` with circular trigonometry node positioning, conflict edge rendering, dynamic color fills, and the decoupled `GraphAnimator` that steps through the precomputed `ExecutionTrace` using JavaFX `Timeline`.

## Requirements Covered
- **REQ-ANIM-01**: Render conflict graph on custom JavaFX `Canvas` with an automated circular mathematical layout.
- **REQ-ANIM-02**: Dynamic visual feedback: highlight active vertex, display candidate color fills, and highlight conflicting edges with adjacent vertices.
- **REQ-ANIM-03**: Animation playback controls: Play, Pause, Step-Forward, and Reset.
- **REQ-ANIM-04**: Live text explanation banner describing the exact algorithmic action occurring at each step in plain English for viva clarity.

## Architecture & Constraints
- Pure custom JavaFX `Canvas` + `GraphicsContext`: Zero external physics or layout libraries.
- Node positioning formula:
  $$\theta_i = \frac{2\pi \cdot i}{N} - \frac{\pi}{2}, \quad x_i = c_x + R \cos\theta_i, \quad y_i = c_y + R \sin\theta_i$$
- Reuses existing `ExecutionTrace` and `AlgorithmStep` classes from Phase 1 without modifications.
- Decoupled playback: `GraphAnimator` advances step-by-step on the JavaFX UI thread without thread locks.

## Tasks

### Task 1: Circular Graph Canvas Component (`com.examguard.ui.GraphCanvas`)
- **Files**:
  - `src/main/java/com/examguard/ui/GraphCanvas.java`
- **Actions**:
  - Extends `javafx.scene.canvas.Canvas`.
  - Maintains:
    - `ConflictGraph graph`
    - `Map<Integer, Integer> vertexColors` (current assigned timeslots)
    - `int highlightedVertex` (-1 if none)
    - `int conflictingNeighbor` (-1 if none)
    - Curated 8-color timeslot palette:
      1: `#4A90E2` (Sky Blue), 2: `#50E3C2` (Aqua Green), 3: `#F5A623` (Warm Amber),
      4: `#BD10E0` (Purple), 5: `#9013FE` (Deep Violet), 6: `#D0021B` (Coral Red),
      7: `#FF69B4` (Pink), 8: `#F8E71C` (Bright Yellow).
      Uncolored: `#EAEAEA` with dark stroke.
  - Trigonometric coordinate helper: `Point2D getVertexPosition(int index, int totalVertices, double cx, double cy, double radius)`.
  - Render method `render()`:
    - Clears canvas.
    - Draws all undirected conflict edges as crisp lines (`#BDC3C7`, width 1.5).
    - If `conflictingNeighbor >= 0` and `highlightedVertex >= 0`, draws the clashing edge in bold red (`#E74C3C`, width 3.5).
    - Draws vertex circles (radius $24\text{px}$) filled with their assigned timeslot color (or uncolored grey).
    - If vertex is `highlightedVertex`, draws an outer golden glow / ring (`#F39C12`, width 3.0).
    - Renders centered subject code text (bold, dark).
  - API methods: `setGraph(ConflictGraph g)`, `resetColors()`, `applyStep(AlgorithmStep step)`, `highlight(int vertex, int neighbor)`.

### Task 2: Animation Playback Controller (`com.examguard.ui.GraphAnimator`)
- **Files**:
  - `src/main/java/com/examguard/ui/GraphAnimator.java`
- **Actions**:
  - Holds references to `GraphCanvas`, `ExecutionTrace`, and a callback/listener `Consumer<AlgorithmStep>` to update the explanation banner and UI buttons.
  - Controls playback using JavaFX `Timeline`:
    - Default keyframe duration: 600ms.
  - State tracking:
    - `int currentStepIndex` (0 .. trace.getStepCount()).
    - `boolean isPlaying`.
  - Methods:
    - `setTrace(ExecutionTrace trace)`
    - `play()`: Starts or resumes timeline.
    - `pause()`: Pauses timeline.
    - `stepForward()`: If `currentStepIndex < trace.getStepCount()`, applies step, increments index, notifies listener.
    - `reset()`: Pauses timeline, resets index to 0, resets canvas colors, notifies listener with initial message.
    - `setSpeedMillis(double ms)`: Updates timeline frame duration.
    - `getCurrentStep()`: Returns the active `AlgorithmStep`.
    - `boolean isFinished()`: Returns true if all steps have been replayed.
