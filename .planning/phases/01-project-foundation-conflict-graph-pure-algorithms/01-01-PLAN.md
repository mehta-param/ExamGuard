# Plan 01-01: Maven Scaffolding, Domain Models & Conflict Graph Builder

## Goal
Establish the Maven project foundation targeting Java 17 LTS and implement the core pure Java domain models and `ConflictGraph` builder that derives undirected clash edges from student course enrollments with zero false conflicts.

## Requirements Covered
- **REQ-GRAPH-01**: Represent subjects as vertices and shared student enrollments as undirected conflict edges.
- **REQ-GRAPH-02**: Provide adjacency list and adjacency matrix representations with graph metrics (vertex count, edge count, vertex degrees, maximum degree $\Delta(G)$).
- **REQ-GRAPH-03**: Verify zero false conflicts and calculate graph density $\frac{2|E|}{|V|(|V|-1)}$.

## Architecture & Constraints
- Pure Java in `com.examguard.model`: Zero `javafx.*` imports to guarantee headless execution and pure DAA separation.
- Fast matrix and array operations backed by integer vertex indices $0 \dots V-1$ while retaining clean object lookups for `Subject`.
- Rich conflict edge metadata: Each edge stores the set of `Student` objects that created the conflict.

### Task 3: Conflict Graph & Builder (`com.examguard.model`)
- **Files**:
  - `src/main/java/com/examguard/model/ConflictGraph.java`
  - `src/main/java/com/examguard/model/ConflictGraphBuilder.java`
- **Actions**:
  - `ConflictGraph`:
    - List of subjects `List<Subject> vertices`.
    - Index mapping `Map<Subject, Integer>` and `Subject[] indexToSubject`.
    - Adjacency list: `Map<Integer, Set<Integer>> adjacencyList`.
    - Adjacency matrix: `boolean[][] adjacencyMatrix`.
    - Edge lookup: `Map<String, ConflictEdge> edges` (keyed by normalized pair, e.g. `min(u,v) + "-" + max(u,v)`).
    - Methods:
      - `int getVertexCount()`
      - `int getEdgeCount()`
      - `int getDegree(int vertexIndex)`
      - `int getMaxDegree()`
      - `double getDensity()`
      - `Set<Integer> getNeighbors(int vertexIndex)`
      - `boolean hasConflict(int u, int v)`
      - `ConflictEdge getEdge(int u, int v)`
      - `Subject getSubject(int vertexIndex)`
      - `int getVertexIndex(Subject subject)`
  - `ConflictGraphBuilder`:
    - `ConflictGraph build(List<Subject> subjects, List<Enrollment> enrollments, List<Student> students)`
    - Maps enrollments by student: `Map<Integer, Set<Integer>> studentToSubjects`.
    - For each student, pairs every two enrolled subjects $(s_a, s_b)$ and creates an undirected conflict edge with the student recorded in `conflictingStudents`.
    - Avoids self-loops ($s_a = s_b$) and duplicate edges.
